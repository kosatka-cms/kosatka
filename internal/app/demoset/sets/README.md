# Demo sets

A demo set is a whole demo site as data, one directory a set and a file
a language: `<name>/<lang>.yaml` (its theme, users, vocabularies, content
types, content, Views, blocks, menus and the modules' demo content).
`app install -demo-set <name>` installs it; a set is offered in the
languages it has a file for.

The format and how to write a set: docs/contributing/demo-sets.md.
